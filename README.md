# Nota

**Nota** — calm, local-first notes. A native Android app written in Kotlin + Jetpack Compose.

Nota is a brand-new, separate build standing alongside [Noma](https://github.com/jubayer00j/noma) (which remains untouched). It keeps Noma's product soul — no server ever sees your notes, Google Drive is only ever your own backup/sync archive, AI is opt-in with your own key — and rebuilds it natively: Material 3 / Material You, Room, and a real design system ("pine & paper").

> This repository is **private while the app is being built**. It will open (MIT) when the app is done.

- **applicationId:** `app.nota.notes`
- **Min Android:** 8.0 (API 26) · **Target:** API 36
- **Version:** 0.1.0 (Phase 0 — foundations)

See `SPIKE-REPORT.md` for the Phase 0 editor spike verdict.
