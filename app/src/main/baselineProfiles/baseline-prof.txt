# Nota baseline profile (Phase 6.1) — HAND-AUTHORED.
#
# Why hand-authored: generating a profile needs a device/emulator
# session (Gradle Managed Devices / a physical device run), which
# this project's CI cannot provide (no KVM, no J7 in the cloud).
# These rules cover the two paths that decide how the app FEELS on
# the J7 Prime: cold start to an interactive notes list, and notes-
# list scrolling. androidx.profileinstaller (already a dependency)
# installs the merged profile at first launch; until now the APK
# shipped with NO profile at all, so a sideloaded install had
# nothing for ART to pre-compile from.
#
# Rule forms used (human-readable format): a bare class descriptor
# includes the class on the startup path; HSPL-prefixed lines name
# hot methods. Unknown or stale rules are ignored by ART — the
# profile is best-effort by design and can never break the app.
